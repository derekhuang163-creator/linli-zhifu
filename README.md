# 邻里智服（Linli Zhifu）

AI 驱动的社区可信上门服务平台。

## 当前 MVP 功能

- 微信小程序用户端：需求输入、风险初筛、服务者推荐、创建订单、订单确认与履约时间轴
- 服务者工作台：查看分配订单、接单、确认到达、开始服务、完成服务
- 后端 API：需求解析、匹配、订单持久化、订单状态机、履约历史
- 服务者审核接口与开发版管理后台
- Node.js 自动化测试：订单状态流转和非法状态跳转

## 本地启动后端

在终端进入 `server/`：

```bash
npm install
npm test
npm run dev
```

服务启动后访问 `http://localhost:3000/health` 检查健康状态。没有 `OPENAI_API_KEY` 时，需求解析使用规则演示模式。

如需启用 AI，在 `server/.env` 配置：

```text
OPENAI_API_KEY=你的API密钥
OPENAI_MODEL=你有权限使用的模型名称
```

不要把密钥提交到 GitHub。

## 小程序连接后端

修改 `miniapp/config.js`：

```js
const API_BASE_URL = "https://你的服务器域名";
module.exports = { API_BASE_URL };
```

正式微信小程序需要配置 HTTPS request 合法域名。当前仓库默认 `API_BASE_URL = ""`，表示使用本地演示模式；本地演示数据仅保存在当前小程序运行内存中，不等于线上持久化服务。

## 当前重要限制

- `/api/auth/dev-login` 是开发登录，不是正式微信身份认证。
- 管理后台 API 支持 `ADMIN_API_TOKEN` Bearer Token；生产环境未配置 Token 时后台 API 默认拒绝访问。浏览器只在当前会话保存 Token。
- 开发登录、下单写入、演示用户订单状态更新及演示服务者履约接口在 `NODE_ENV=production` 下被禁用；正式身份与权限认证尚未接入，因此当前版本不能直接承接真实生产订单。
- 支付、退款、保险、真实定位、真实距离排序尚未接入。
- 服务者工作台目前使用演示服务者身份；上线前必须增加服务者登录、身份核验和订单授权。
- 正式上线前需要安全审查、隐私合规、支付结算合规和端到端测试。

## 产品路线

1. 稳定用户下单—服务者履约—用户验收的完整状态链路。
2. 完成微信用户登录、服务者身份与权限。
3. 将 JSON 文件存储迁移到正式数据库并备份。
4. 增加管理员认证、审核操作和审计日志。
5. 进行支付、退款、售后、保险和隐私合规接入。


## 管理后台安全配置

本地开发可不设置 Token。部署环境需设置 `NODE_ENV=production` 和一个随机的 `ADMIN_API_TOKEN`（建议至少 32 字节随机值），并通过 HTTPS 访问后台。不要把 Token 写进代码仓库或发给用户。生产环境在完成微信用户/服务者身份认证、订单权限校验及正式数据库迁移前，不应开放真实下单运营。

## 正式上线阻断项（2026-10）

**当前状态：禁止直接接入真实订单运营。** `GET /ready` 会列出尚未关闭的上线阻断项；HTTP 503 表示不可上线，不应通过删除检查项来绕过。

### 当前账号主体是个人主体

邻里智服计划撮合第三方服务者提供多种上门服务，并有订单与支付结算。个人主体是否可以选择与实际业务匹配的服务类目、开展该经营模式，必须在微信公众平台以当前账号实际开放类目核验；不能仅凭代码判断，也不能通过隐藏页面绕过类目审核。建议在投入服务器和支付开发前，先确认该主体是否具备目标业务资格；如不具备，应先办理适合的企业/个体工商户主体及相关经营资质，再继续开放真实交易。

### 从零部署

1. 选择支持中国大陆访问、可办理 ICP 备案的云服务商和地域；购买并实名认证域名，按服务商指引完成 ICP 备案。微信小程序请求域名需为已备案的 HTTPS 域名，不能使用 IP 或 localhost。
2. 在部署环境设置 `NODE_ENV=production`、`PORT=3000`、`DATA_DIR=/data`、`ADMIN_API_TOKEN`（使用密钥管理功能保存至少 32 字符随机值）。不要把真实密钥提交到 GitHub。
3. 将 `/data` 挂载到持久化磁盘。当前 JSON 存储只适合开发/小规模验证，不满足正式订单系统的并发、备份、审计和恢复要求；上线前必须迁移到受管理数据库并演练备份恢复。
4. 部署后检查 `/health` 和 `/ready`。当前 `/ready` 预计返回 503，直到真实身份认证、服务者授权、数据库、支付和合规事项全部完成。这是有意的安全阻断。
5. 在微信公众平台配置合法 request 域名，并把 `miniapp/config.js` 中的 `API_BASE_URL` 设置为最终 HTTPS API 域名；不要在开发工具中依赖关闭域名校验的设置。
6. 当前个人主体与多类上门服务撮合模式的适用性、支付商户申请资格和实际服务类目必须先得到平台/专业合规确认。不要在确认前收取真实款项。

### 生产安全边界

- 开发身份、下单写入、订单详情、服务者注册/履约及开发状态接口在生产环境被禁用，避免未认证用户查看或修改真实订单。
- 管理 API 在生产环境必须使用 `ADMIN_API_TOKEN`；此 Token 只是过渡性运维保护，不等于完整的多管理员 RBAC、审计系统或企业级认证。
- 当前项目没有正式微信登录、支付/退款、正式数据库迁移、服务者身份核验和隐私同意闭环，因此不能宣称已经具备生产运营条件。
